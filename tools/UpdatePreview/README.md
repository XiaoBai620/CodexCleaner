# 更新功能演示

在 Windows、.NET 10 SDK 环境中，从仓库根目录运行：

```text
dotnet run --project tools/UpdatePreview
```

工具复用正式程序的主窗口和更新窗口。启动后会出现虚构 **v9.0.0** 更新：

1. 在主窗口查看更新摘要，点击「查看并更新」阅读完整说明。
2. 点击「下载并重启」，体验约 20 秒的模拟下载进度。
3. 点击「取消下载」，可在当前窗口点击「重新下载」。
4. 完成模拟下载后会显示成功提示，回到主窗口可再次点击「查看并更新」体验。

检查、下载、安装和发布页按钮全部注入模拟实现，不发送网络请求，不生成或启动更新程序，不替换文件、不重启。v9.0.0 只是演示版本，并非正式发布。

演示显式使用新建临时目录中的两条虚构会话，不读取 `CODEX_HOME` 或真实 `.codex` 数据。临时数据库复用仓库的测试结构，不引用测试框架。清理、备份等主窗口操作也只作用于此隔离目录。正常退出会清除本次临时目录；若清除失败会提示具体路径。

发布应用时无需包含此工具。
