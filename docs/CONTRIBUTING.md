# 贡献指南

开发环境为 Windows 10/11 和 .NET 10 SDK。修改前后运行 `dotnet test tests/CodexCleaner.Tests`；界面修改还需要用虚构数据手动检查列表、搜索、全选、确认窗口和 Codex 运行时的禁用状态。

## 数据处理原则

- 所有自动测试使用 `tests/CodexCleaner.Tests/Fixture.cs` 在临时目录生成的合成数据，测试结束后清理。不要把个人数据库、日志、聊天文件或 `.codex` 目录复制进仓库。
- 修复要先复现问题，再增加能验证用户结果的回归测试。涉及删除的改动要同时确认未选聊天、项目、远端引用和未知文件保持不变。
- 不通过跳过结构检查、关闭进程检测或放宽路径限制来解决兼容问题。
- 适配新版数据库时，要核查新增的表、列、触发器、级联关系和桌面引用，并补充删除动作与回滚测试；只更新指纹不足以证明兼容。
- 保持手动预览加一次确认的流程，不增加后台自动删除、确认词输入或日常可恢复区。

## 提交

PR 说明问题如何触发、修改后的行为、验证结果和仍未验证的范围。不要在 Issue、PR、截图或录屏中包含真实聊天、带用户名的路径或认证信息。

版本只在 `src/CodexCleaner/CodexCleaner.csproj` 中维护，窗口标题显示同一版本。新增 NuGet 依赖请固定版本，并说明理由。
