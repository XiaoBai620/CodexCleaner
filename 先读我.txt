Codex 本地清理台

紧凑界面：顶部导航、搜索与修复并排、清理选项紧邻列表。
预览内的文件和数据库明细可以展开，不再有大标题及统计卡片。

新版不再要求输入“清理”“永久清理”，不设可恢复区。
预览后点击一次确认，成功后不保留聊天恢复副本。

开始使用
1. 退出旧版清理工具。将新版 ZIP 完整解压到单独文件夹，请保留所有文件。
2. 退出 Codex / ChatGPT 桌面应用、Codex 命令行，以及其他写入同一数据目录的进程。
3. 双击 Start-CodexCleaner.cmd，在默认浏览器中打开工具。
4. 之前有项目/归档错误时，点击“检查失效引用”，核对预览后点击“确认修复”。
   标为“会话文件已缺失”的旧聊天仍需按需勾选删除残留索引；修复不会重建已丢失的正文。
5. 勾选聊天；按需要勾选“全部本地记忆”和“共享输入历史与日志”。
6. 点击“预览清理范围”，核对聊天、文件和数据库，再点击“确认删除”，无需输入确认词。
7. 完成后点击顶部“退出工具”（窄屏为电源图标），再启动 Codex。单纯关闭网页不会立即关闭后台进程。

主要功能
聊天记录：按标题或 ID 搜索并勾选聊天，归档记录也会显示。
本地记忆：清空已识别的本机记忆；不会自动关闭 Codex 的记忆功能。
文件用途：逐层展开目录，查看用途和处理方式；未知文件会明确标注并保留。
检查失效引用：移除项目迁移、归档/置顶、未读等已识别字段对不存在聊天的引用。
修复保留有效聊天、项目定义、远端主机引用；不能保证解决其他来源的应用错误。

说明
需要 Windows 10/11 和已安装的 Node.js 24 或更新版本，无须安装 npm 依赖。
未安装 Node.js 时请从 https://nodejs.org/ 获取，发布包不包含运行环境。
当前版本显示在工具左上角；支持结构核查于 2026-09-27，并非兼容所有 Codex 版本。
仅在本机回环地址运行，不会上传记录，没有定时清理或开机自动运行。
数据库格式不匹配时会拒绝清理，需要更新工具来适配新版 Codex。
插件、技能、设置、登录信息和项目文件保留。
清理成功后不能通过本工具撤销；这是普通文件删除，不是磁盘安全擦除。
执行期间的临时事务副本会在成功或成功回滚后自动删除，不是日常可恢复区。
若断电、强制结束或回滚失败，工具会显示故障位置；保持 Codex 关闭并处理故障后再继续。
新版启动时不会自行删除旧版 Recovery 文件夹。
工具按当前已验证格式独立制作，不是 Codex 官方功能。
云端记录、语音文件、项目内副本、系统备份和未识别的数据不在自动清理范围。
